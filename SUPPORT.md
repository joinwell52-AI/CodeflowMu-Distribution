# CodeFlowMu Preview Support

CodeFlowMu Distribution is currently a free public preview. Support is best effort; there is no uptime, compatibility, response-time or maintenance SLA.

## Before opening an issue

1. Confirm that you are using a Release downloaded from this repository.
2. Record the CodeFlowMu version, Windows version and whether the problem concerns the PC product, Mobile PWA, Gateway or an external Provider.
3. Reproduce the problem with the smallest safe project and remove customer data.
4. Check the Release notes for known blockers, especially Provider compatibility status.

## Where to ask

- Reproducible product bugs: [GitHub Issues](https://github.com/joinwell52-AI/CodeflowMu-Distribution/issues)
- Preview feedback and feature proposals: [GitHub Issues](https://github.com/joinwell52-AI/CodeflowMu-Distribution/issues)
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md) and report privately

An issue should include expected behavior, actual behavior, reproduction steps and sanitized logs or screenshots. Never include API keys, QR/bind links, access tokens, private source code, customer tasks or personal data.

## Support boundaries

- Candidate releases may be incomplete, unsigned, incompatible with an upstream Provider update or replaced by a later candidate.
- CodeFlowMu cannot provide support for the customer's Provider account, billing, service availability or upstream terms.
- The Mobile PWA, Gateway, PC application and Provider runtime have separate version lifecycles.
- CodeFlowMu-open is maintenance-frozen historical software; its behavior does not define support for CodeFlowMu Distribution.
